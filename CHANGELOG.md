# Histórico de versões

Todas as versões estão disponíveis como *tags* no GitHub (aba **Tags**).
Tags com sufixo `-ms2` / `-ms3` são das linhas para MuseScore 2 e 3.

## v0.23 — 2026-08-17

- Compatível com o MuseScore 4.4+ (QtQuick.Controls 2.15 / Qt.labs.platform).
- Caixa de mensagens de erro atualizada.
- Não escreve mais o rótulo "(1 e 2):" antes do primeiro intervalo.
- Novo ícone.
- Título do plugin corrigido para "Intervalos".

## v0.21.1-ms3 — 2025-01-02

Versão de manutenção para MuseScore 3.

- Não escreve mais o rótulo "(1 e 2):" antes do primeiro intervalo.

## v0.22 — 2024-09-18

- Compatibilidade com o MuseScore 4.
- Ícone do plugin.

## v0.21 — 2020-08-19

Versão para MuseScore 3.

- Menu passa a ser **Plugins ▸ Contraponto ▸ Intervalos**.

## v0.21-ms2 — 2020-05-27

Última versão para MuseScore 2.

- Menu passa a ser **Plugins ▸ Contraponto ▸ Intervalos**.

## v0.2 — 2019-11-12

Versões para MuseScore 3 (`v0.2`) e MuseScore 2 (`v0.2-ms2`, 2019-11-24).

- Intervalos em contrapontos a mais de 2 vozes.
- Correção do posicionamento automático do texto.
- Correção do nome no menu.

## v0.1 — 2019-09-25

- Primeira versão, para MuseScore 2.
